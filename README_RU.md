# Syncleo для Home Assistant — форк Lepi4

Локальное управление совместимыми устройствами Rusclimate/Polaris по Wi-Fi (UDP)
без MQTT. Основан на [DeKaN/ha-syncleo](https://github.com/DeKaN/ha-syncleo) 0.7.0.
Лицензия MIT: [исходная лицензия](LICENSE), [уведомление pysyncleo](custom_components/syncleo/PYSYNCLEO-LICENSE.txt).

Требуется **Home Assistant 2026.10.0 или новее**, доступ к устройству по UDP и mDNS.
[Поддерживаемые модели](supported_models.md) · [Изменения](CHANGELOG.md) · [English](README.md).

## Что исправлено в форке

Если устройство подтверждает пакет ACK, но не завершает handshake, соединение
больше не остаётся навсегда в CONNECTING. Через 10 секунд срабатывает тайм-аут,
после которого существующий механизм переподключения может повторить попытку.
Подробности и ограничения: [описание исправления](custom_components/syncleo/LOCAL-PATCH.md).

## Установка

1. Откройте **Настройки → Marketplace → Добавить по ссылке**.
2. Укажите `https://github.com/Lepi4/ha-syncleo`.
3. Откройте репозиторий и установите последний опубликованный релиз.
4. После обновления уже загруженной интеграции выполните перезапуск, предложенный Home Assistant.

Для HACS добавьте тот же адрес как пользовательский репозиторий типа **Integration**.
Форк и исходный проект используют один домен `syncleo`; выбирайте один источник
обновлений. Перед переходом с другого источника создайте резервную копию Home Assistant.
Домен и формат настроек в 0.7.1 не менялись.

Для ручной установки скачайте `syncleo.zip` из
[Releases](https://github.com/Lepi4/ha-syncleo/releases/latest), распакуйте содержимое
в `<config>/custom_components/syncleo/` и перезапустите Home Assistant.
Файл `manifest.json` должен оказаться непосредственно в этой папке.

## Добавление устройства

Дождитесь автоматического обнаружения устройства через mDNS. В мобильном приложении
откройте настройки устройства → управление доступом → поделиться. Полученную Share URL
вставьте в форму настройки Syncleo. При необходимости уточните производителя и модель.
Share URL содержит токен: не публикуйте её в сообщениях об ошибках.

## Ошибка 404 при установке

Ошибка для `releases/download/main/syncleo.zip` означает попытку скачать ZIP несуществующего
релиза `main`. Обновите информацию репозитория и выберите **v0.7.1** или более новый релиз.
Не удаляйте устройства и сохранённые настройки ради повторной загрузки.

Если загрузка опубликованного релиза также не проходит, приложите версию Home Assistant,
версию интеграции и точную строку ошибки к
[обращению в форке](https://github.com/Lepi4/ha-syncleo/issues).

## Проверка восстановления

Семь offline-тестов проверяют тайм-аут, повторное подключение, очистку сессии и
изоляцию устройств без обращения к настоящим устройствам. Физическое отключение
питания устройства для этого релиза не проверено.
